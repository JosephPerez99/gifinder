# GIFinder
Aplicación frontend desarrollada con Vite y TypeScript para consultar,
buscar y visualizar contenido multimedia mediante la API de Giphy.

## Tecnologias

- HTML
- CSS
- TypeScript
- Vite
- PNPM

## Requisitos
- Node.js LTS
- PNPM

## Instalacion
```bash
pnpm install
```
## Ejecucion
```bash
pnpm dev
```
## Compilacion
```bash
pnpm build
```

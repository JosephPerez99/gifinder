# Preguntas de cierre

## 1. ¿Qué aprendiste durante la actividad?

Aprendí a crear un proyecto utilizando Vite y TypeScript, instalar dependencias y ejecutar el proyecto mediante pnpm.

## 2. ¿Para qué sirve Vite?

Vite es una herramienta que permite crear y ejecutar proyectos frontend de manera rápida, proporcionando un servidor de desarrollo y herramientas para construir el proyecto.

## 3. ¿Para qué sirve TypeScript?

TypeScript permite agregar tipos al código JavaScript, ayudando a detectar errores y haciendo que el código sea más fácil de mantener.

## 4. ¿Qué función tiene package.json?

El archivo package.json contiene información del proyecto, sus dependencias y los comandos que se pueden ejecutar.

## 5. ¿Por qué se utiliza .gitignore?

Se utiliza para evitar que archivos innecesarios o sensibles, como node_modules, dist y archivos .env, sean enviados al repositorio.
